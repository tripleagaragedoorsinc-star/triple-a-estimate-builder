# Triple A Smart Estimate Builder

Internal garage-door installation estimate prototype.

## Deployment

Static `index.html` can be hosted on a static hosting provider. This prototype is not production-secure; do not enter confidential supplier costs or customer data until authenticated backend and row-level authorization are implemented.

## Roadmap

- Installation estimate pricing and supplier order checklist
- Owner-only supplier cost history and price updates
- Supabase authentication and secure data storage
- ServiceTitan estimate export
- Separate repair-estimate module
